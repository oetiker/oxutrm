# OSC 52 Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A remote program's OSC 52 clipboard copy reaches the user's local terminal exactly once, survives packet loss, and is never replayed to a client that did not see it made.

**Architecture:** The copy rides on the replicated `ScreenState` as a `clipboard` field (a monotonic `serial` plus the latest copy), so the existing diff/ack machinery carries it. The host captures it from the emulator and drops the text once the client has acknowledged a state carrying it. On the client, a `ClipboardRelay` turns a rising serial into one `ESC ] 52 ; c|p ; base64 BEL`, keyed per session, gated by the new `terminal.clipboard` setting.

**Tech Stack:** Rust 2024 (MSRV 1.96), `alacritty_terminal` 0.26 (emulator), `postcard` + `serde` (wire), `base64` 0.22, `quinn` (tests over real QUIC), `insta` (config-screen snapshot).

**Spec:** [docs/superpowers/specs/2026-10-16-osc52-osc8-design.md](../specs/2026-10-16-osc52-osc8-design.md) §1–§3, §5–§8 (PR 1 only; OSC 8 is a later plan).

## Review Focus

1. **A copy made before the client's first state arrives** (a program that copies in the first milliseconds of a new session). The relay treats the first state of a session as the baseline, so that copy is not written. This is the decided stale rule (spec row 4) and is pinned by Task 6's `a_fresh_client_never_writes_a_copy_made_before_it_arrived`; reviewers should know it is intended, not a race.
2. **A copy whose bytes are not UTF-8** (a binary yank). The emulator drops it before it reaches oxutrm; the next valid copy still counts. Pinned in Task 3: `a_copy_that_is_not_utf8_never_reaches_the_state`.
3. **An empty copy** (`printf '\e]52;c;\a'`, which clears the clipboard in many terminals). Passed on as an empty OSC 52. Pinned in Task 5: `an_empty_copy_is_passed_on_because_it_clears_the_clipboard`.
4. **A copy whose text contains ESC/BEL** (copying coloured terminal output). Accepted by I8 and carried inside the base64, so it can never act as control. Pinned in Task 1 (`i8_a_clipboard_copy_may_hold_controls_…`) and Task 5 (`controls_in_the_text_travel_inside_the_base64`).
5. **A copy made while the popup, config screen or selector is open.** Written anyway: the relay sits in `take_frames`, which runs whatever layer 1 shows. No dedicated test (opening the popup in the QUIC fixtures is heavy); the reviewer of Task 6 checks that the write is not gated on `self.ui` or `self.shown`.

//! A remote program's clipboard write (OSC 52), as part of the screen state.
//!
//! # Why a field and not a message
//!
//! A copy is an event, but it rides on the replicated state the same way the
//! bell does: a monotonic counter plus the latest value. A lost datagram then
//! costs nothing, because the next diff from the same acknowledged base still
//! carries it, and a reattach or a ring miss needs no rules of its own. A
//! separate message would need its own reliability, its own demux and its own
//! answer to "replay this after a reconnect?".
//!
//! # Why `serial` is separate from `copy`
//!
//! The host drops the text once the client has acknowledged a state that
//! carries it, so later full states stay small and a later client never sees
//! stale clipboard content. The serial stays: it is what tells a client
//! whether a copy is one it has already written.
//!
//! # Safety
//!
//! The text is never painted. The client base64-encodes it into one OSC 52,
//! so control characters in it cannot reach the terminal as control, and only
//! its length is bounded (**I8**). The OSC 52 rule in `text.rs` that keeps
//! clipboard writes out of *cells* is untouched by this.

use std::sync::Arc;

use serde::{Deserialize, Serialize};

use crate::{ApplyError, MAX_CLIPBOARD, TextField};

/// Which clipboard a copy is for.
///
/// The emulator distinguishes these two: OSC 52's `c` is `Clipboard`, `p` and
/// `s` are `Selection`. Any other target letter never reaches the state.
#[derive(Clone, Copy, PartialEq, Eq, Debug, Serialize, Deserialize)]
pub enum ClipboardTarget {
    Clipboard,
    Selection,
}

/// One copy: where it goes and what it says.
#[derive(Clone, PartialEq, Eq, Debug, Serialize, Deserialize)]
pub struct ClipboardCopy {
    pub target: ClipboardTarget,
    /// `Arc` because the sender keeps a ring of recent states and each clone
    /// would otherwise copy up to [`MAX_CLIPBOARD`] bytes.
    pub text: Arc<str>,
}

/// The clipboard part of a [`ScreenState`](crate::ScreenState).
#[derive(Clone, PartialEq, Eq, Debug, Default, Serialize, Deserialize)]
pub struct Clipboard {
    /// How many copies this session has made. Monotonic, like `bell` (**I9**):
    /// the client writes a copy when this rises past the last value it saw.
    pub serial: u32,
    /// The latest copy, until the client has acknowledged a state that
    /// carries it. `None` before the first copy and after delivery.
    pub copy: Option<ClipboardCopy>,
}

impl Clipboard {
    /// The same clipboard, minus its text. What a state shows once the copy
    /// has been delivered, and what a preview of another session must show.
    pub fn without_text(&self) -> Clipboard {
        Clipboard {
            serial: self.serial,
            copy: None,
        }
    }
}

/// **I8** for the clipboard: at most [`MAX_CLIPBOARD`] bytes of text.
///
/// Controls are allowed on purpose -- see the module comment.
pub fn check_clipboard(c: &Clipboard) -> Result<(), ApplyError> {
    if let Some(copy) = &c.copy
        && copy.text.len() > MAX_CLIPBOARD
    {
        return Err(ApplyError::TextTooLong {
            field: TextField::Clipboard,
            len: copy.text.len(),
            max: MAX_CLIPBOARD,
        });
    }
    Ok(())
}

#[cfg(test)]
mod tests {
    use super::*;

    fn with(text: &str) -> Clipboard {
        Clipboard {
            serial: 1,
            copy: Some(ClipboardCopy {
                target: ClipboardTarget::Clipboard,
                text: text.into(),
            }),
        }
    }

    #[test]
    fn a_copy_of_exactly_the_cap_is_accepted_and_one_byte_more_is_not() {
        assert_eq!(check_clipboard(&with(&"x".repeat(MAX_CLIPBOARD))), Ok(()));
        assert_eq!(
            check_clipboard(&with(&"x".repeat(MAX_CLIPBOARD + 1))),
            Err(ApplyError::TextTooLong {
                field: TextField::Clipboard,
                len: MAX_CLIPBOARD + 1,
                max: MAX_CLIPBOARD,
            })
        );
    }

    #[test]
    fn controls_in_a_copy_are_allowed_because_it_is_never_painted() {
        assert_eq!(check_clipboard(&with("a\x1b]52;c;?\x07\nb")), Ok(()));
    }

    #[test]
    fn without_text_keeps_the_serial() {
        let c = with("secret").without_text();
        assert_eq!(c.serial, 1);
        assert_eq!(c.copy, None);
    }

    #[test]
    fn the_text_round_trips_through_postcard() {
        let c = with("héllo");
        let back: Clipboard = postcard::from_bytes(&postcard::to_stdvec(&c).unwrap()).unwrap();

//! Writing a remote program's clipboard copy (OSC 52) to the local terminal.
//!
//! Kept out of [`crate::Renderer`] on purpose: the renderer also paints
//! things that must never write the clipboard -- the popup, and a preview of
//! another session -- and a relay that only sees the states it is handed
//! cannot be reached by those.
//!
//! # When a copy is written
//!
//! The state carries a serial that counts every copy the session has made.
//! A copy is written when that serial rises past the last one this client
//! process saw **for that session**. The first state of a session sets the
//! baseline and writes nothing: a copy made before this client arrived is
//! stale, and overwriting the user's local clipboard with it would be a
//! surprise. A client that reconnects in the same process keeps its baseline,
//! so a copy made during an outage still arrives, once.

use std::collections::HashMap;

use base64::Engine as _;
use oxutrm_proto::{Clipboard, ClipboardTarget, SessionId};

/// Decides which copies reach the terminal, and how they are spelled.
pub struct ClipboardRelay {
    /// The terminal understands OSC 52 at all (`TerminalCaps::osc52`).
    osc52: bool,
    /// The last serial seen per session. `None` is a session with no id --
    /// a test fixture, or `oxutrm loopback`.
    seen: HashMap<Option<SessionId>, u32>,
}

impl ClipboardRelay {
    pub fn new(osc52: bool) -> ClipboardRelay {
        ClipboardRelay {
            osc52,
            seen: HashMap::new(),
        }
    }

    /// The bytes to write for a newly applied state of `session`, if any.
    ///
    /// `enabled` is the `terminal.clipboard` setting. Off still advances the
    /// baseline, so turning it on later does not replay an old copy.
    pub fn on_state(
        &mut self,
        session: Option<SessionId>,
        c: &Clipboard,
        enabled: bool,
    ) -> Option<Vec<u8>> {
        let last = self.seen.insert(session, c.serial)?;
        if c.serial <= last {
            // Never moves the baseline down: a lower serial is a state the
            // receiver should have refused (I9), not a new session.
            self.seen.insert(session, last);
            return None;
        }
        let copy = c.copy.as_ref()?;
        if !(enabled && self.osc52) {
            return None;
        }
        let target = match copy.target {
            ClipboardTarget::Clipboard => "c",
            ClipboardTarget::Selection => "p",
        };
        let encoded = base64::engine::general_purpose::STANDARD.encode(copy.text.as_bytes());
        let mut out = Vec::with_capacity(encoded.len() + 8);
        out.extend_from_slice(b"\x1b]52;");
        out.extend_from_slice(target.as_bytes());
        out.push(b';');
        out.extend_from_slice(encoded.as_bytes());
        out.push(0x07);
        Some(out)
    }
}

## Judgement calls and spec deviations (recorded in the spec, §10)

1. **Ack hook (spec §3.4 left it open):** `Sender::acked()` exposes the acknowledged state; `HostSession::turn_at` checks it right after taking inbound frames and sets `screen_stale` so the text-less snapshot goes out even on a quiet pty.
2. **`serde` `rc`:** enabled workspace-wide (one line); `ClipboardCopy.text` is `Arc<str>`.
3. **Diff comparison:** the diff compares the whole `Clipboard`, not "serial and presence" as the spec said. `Arc<str>` equality checks the pointer first, so it is as cheap, and it is simply correct.
4. **Over-cap log line:** `HostTerm` does not print (it runs inside the client in `oxutrm loopback`, where stderr is the painted terminal); it records the length and `HostSession` prints it.
5. **Relay key:** `Option<SessionId>`; `None` is a session with no identity (test fixtures, `oxutrm loopback`).
6. **Write errors:** the OSC 52 write propagates like the render write next to it; the spec's "the session continues" is replaced by "handled like a render write error".
7. **First-state baseline consequence:** a copy made before the client's first state of a session arrives is not written (Review Focus 1). The end-to-end tests therefore let the client apply a first state before the shell copies (`read go`).
8. **Config screen:** `terminal` is a new fourth section; the 80x24 snapshot gains two lines.
9. **Not wired:** `oxutrm loopback` (a developer mode) does not write copies; it has no `ClientSession`.
